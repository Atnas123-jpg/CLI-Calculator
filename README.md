# 🧮 Simple CLI Calculator

A simple **Command Line Interface (CLI) Calculator** developed using **Java**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage
- ( ) Brackets
- ^ Power
- √ Square Root
- 🔢 Decimal numbers
- 📜 Calculation History
- 🗑️ Clear History
- 🚪 Exit

## 🛠️ Technology

- Java
- Git & GitHub

## ▶️ How to Run

Run `Calculator.java` and enter a calculation.

**Commands:**
- `history` — View calculation history
- `clear` — Clear history
- `exit` — Close the calculator
